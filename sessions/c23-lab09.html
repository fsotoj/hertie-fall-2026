What lab 8 covered, and what it suggests

Lab 8 was a tour of lecture 8: matrix products, transpose, norm, determinant, independence, inverse and a step-by-step SVD, each computed by hand first and then checked with NumPy. The syllabus lists the ISLR 12.5.1 PCA lab as “will do together in lab” for the session whose readings we have now.

A reasonable guess: gradients of linear and quadratic functions checked numerically; a small Lagrange problem by hand and then with SciPy; PCA from scratch by centring, the covariance matrix and its eigenvectors, then the same through the SVD; variance explained and a scree plot; scaled against unscaled data. The course environment has NumPy, SciPy, pandas and matplotlib but not scikit-learn, so PCA would be done with np.linalg. That is an inference.

Traps worth knowing before you start. np.linalg.eigh returns eigenvalues in ascending order, so the first component is the last column until you reverse it. np.linalg.svd returns Vᵀ, so loadings are its rows. np.cov treats rows as variables unless you pass rowvar=False. Centre before the SVD. Loadings are unique only up to sign. And ∇(xᵀAx) = 2Ax needs A symmetric; in general it is (A + Aᵀ)x.

Checks worth doing by hand first

  • Minimum of x + y on the unit circle: x = y = −1/√2, value −√2.
  • Maximum of xy with x + y = 10: 25 at (5, 5); one more unit of budget is worth about 5, which is what the multiplier measures.
  • Covariance [[2, 1], [1, 2]]: eigenvalues 3 and 1, first component (1, 1)/√2, 75% of the variance.
  • Least-squares line through (0, 1), (1, 2), (2, 2): intercept 7/6, slope 1/2, from the normal equations.

What you should be able to do afterwards

  • Check a gradient numerically
  • Solve a small constrained problem and say what the multiplier means
  • Run PCA by eigen-decomposition and by SVD and show they agree
  • Read loadings, scores and a scree plot, and decide whether to scale
